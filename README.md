# speech-recognition-datasets
This repository contains scripts which download datasets for speech recognition, adds train/test splits, creates tables and more. The datasets are then pushed to `huggingface`.

## Installation

Please install the `requirements` under Linux as follows:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Please install the `requirements` under Windows as follows:

```powershell
python -m venv .\.venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```
