# subesco

## Description

This directory contains scripts to download the `subesco` dataset from Zenodo ([SUST Bangla Emotional Speech Corpus (SUBESCO)](https://zenodo.org/records/4526477)).

## Installation

Install the requirements as [explained](../../README.md).

## Usage

Then you can download, process and push the data to `huggingface` by running:

```bash
python download.py
python create.py
python publish.py
```
